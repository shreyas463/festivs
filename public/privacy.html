Privacy

Festivs is a card you write and send as a link. The note, the names, the festival, and the effects are the address itself.

  • Festivs does not keep a copy of the card. There is no account and no database.
  • Save image downloads a picture to your device. Festivs does not receive that file.
  • Anyone who has the link can read the card. Send it only to the people you want to read it.
  • The type is loaded from Google Fonts, so opening a page requests those font files from Google.
  • GitHub Pages hosts the site and may keep its own request logs.
